# RK Harvester Fresh Dashboard

Fresh responsive dashboard built with plain HTML, CSS, and JavaScript.

## Open

Open `index.html` in any browser.

## Login

- Username: `owner`
- Password: `1234`

## Included

- Desktop sidebar navigation
- Mobile slide-out sidebar
- Dashboard metrics
- Work entries with amount-per-acre auto total
- Customer details inside work entries
- Expenses for Food, Diesel, and Other with harvester selection
- Harvesters with assigned operators
- Staff users
- Role-based access: owner sees all pages, operators see only Work Entries and Expenses
- JSON backup and import
- Browser localStorage persistence
